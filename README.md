# Nova Binder

Биндер Nova RP. Разработчик: Lunar Stellar.

## Установка

1. Скачайте файл NovaBinder-Setup-….exe из раздела Releases справа.
2. Запустите его. Windows может предупредить о неподписанном файле: нажмите «Подробнее», затем «Выполнить в любом случае».
3. Новые версии программа предложит поставить сама.
