# Nova Binder

Панель быстрых ответов и функций для окна «Помощь игроку» на проекте Nova RP.

## Установка

1. Скачайте установщик по постоянной ссылке, она всегда ведёт на самую свежую версию:
   https://github.com/debumich/novabinder-releases/releases/latest/download/NovaBinder.exe
2. Откройте скачанный файл. Больше ничего нажимать не нужно: программа установится сама и запустится.
3. Windows может предупредить, что файл не подписан. Нажмите «Подробнее», затем «Выполнить в любом случае».
4. Программа работает от имени администратора, чтобы Windows пропускал ввод и в игру, запущенную от администратора.
   Windows спросит подтверждение при запуске: нажмите «Да».

## Обновления

Новые версии программа находит и ставит сама: появится окно «Вышла версия» с кнопкой «Обновить». Скачивать установщик
заново не нужно.
